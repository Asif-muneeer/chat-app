Firebase Setup — Live Karne Ke Liye

GitHub Pages sirf front-end host karta hai. Asal login, database aur storage ke liye Firebase free project chahiye. Ye steps Alex ko karne hain — iske baghair chat cross-device live nahi hogi.

  1. console.firebase.google.com par jao → Add project → naam do e.g. chat-app
  2. Authentication → Sign-in method → Email/Password ON karo
  3. Firestore Database → Create database
  4. Storage → Get started
  5. Project Settings → Your apps → Web app (</>) → wahan se firebaseConfig copy karo
  6. Neeche box me paste karke Connect dabao — is session ke liye live ho jayega. Permanent GitHub live ke liye wahi config is file ke top script me FIREBASE_CONFIG me daal kar GitHub par push karna hoga.

Secure Rules (Firestore me paste karo):

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid} { allow read: if request.auth != null; allow write: if request.auth.uid == uid; } match /chats/{chatId} { allow read, update: if request.auth.uid in resource.data.members; allow create: if request.auth.uid in request.resource.data.members; match /messages/{msgId} { allow read, create: if request.auth.uid in get(/databases/$(database)/documents/chats/$(chatId)).data.members; } } } }

Is rule se sirf login wala user, aur sirf apni chat ke members, messages dekh sakte hain. Koi bahar wala nahi.

18+ Community & Safety Rules

  • Sirf 18+ — 18 se kam age par account block ho jata hai. Jhooti age dena violation hai.
  • Kisi ko harass, threaten ya spam mat karo. Block / Report har chat me hai.
  • Illegal content, hate, ya bina permission kisi ki private photo/video share karna mana hai.
  • Apna password, OTP, CNIC, bank/card details kabhi chat me mat bhejo.
  • Kisi stranger se paisay ya gift card mat bhejo. Scam lage to foran Report karo.
  • Video call par koi record kare to pehle permission lo.
